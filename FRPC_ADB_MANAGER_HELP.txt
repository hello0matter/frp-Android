FRPC / ADB 设备管理器操作说明
================================

一、基本流程
------------
1. 启动 scripts\manage-frpc.bat。
2. 左侧“在线 ADB 设备”选择手机。
3. 右侧编辑服务器、端口、Token、ADB 和 FRPC 选项。
4. 点击“保存归档”保存当前设备配置。
5. 点击“在线操作...”执行安装、启动、停止、重启、卸载或读取详情。

设备归档保存在 scripts\profiles\。归档是电脑上的记录，不等于手机当前实际状态。
双击左侧归档可以加载并查看详情；双击在线设备可以读取手机实际配置。

二、FRPC 与 ADB 的区别
----------------------
“仅 ADB”只安装 ADB 开机恢复脚本，用于恢复 adbd、USB 调试和 TCP 5555。
“FRPC + ADB”安装 FRPC 客户端，同时可以附带 ADB 开机恢复脚本。
两者在手机上是两个独立服务。FRPC 不负责修改 USB 调试，ADB 也不负责启动 FRPC。
如果已经有旧版 ADB 恢复脚本，安装时手机端会按状态文件判断并替换受管理的旧脚本。

三、FRPC 定时自检与定时执行段落
------------------------------
勾选“启用 FRPC 定时自检”，填写周期秒数，最小 10 秒。
定时器运行在手机端 SH 中，不依赖电脑程序常驻。

“定时执行段落”是一个多行 Shell 编辑框。默认内容是结束当前 FRPC 子进程，
然后由 supervisor 自动拉起同一个 FRPC。你可以直接在默认内容下面继续写自己的命令，
也可以删掉默认内容后写完整的自定义段落。代码会按从上到下的顺序执行。

修改后必须点击“保存归档”，再重新安装或推送 FRPC 服务，手机端 SH 才会更新。
在线读取设备时，程序会从手机 SH 的 BEGIN/END 标记之间读取实际段落。

段落可以使用这些服务变量：
  $CHILD_PID       FRPC 子进程 PID 文件
  $SUPERVISOR_PID  supervisor PID 文件
  $LOG             随机日志文件路径
  $LOG_ENABLED     日志开关，值为 1 或 0
  $BIN             FRPC 二进制路径
  $CONFIG          FRPC TOML 路径
  $INSTALL_DIR     FRPC 随机数据目录

示例：检查标记文件后重启 FRPC：
  if [ -f "$INSTALL_DIR/restart.flag" ]; then
      rm -f "$INSTALL_DIR/restart.flag"
      kill "$(cat "$CHILD_PID" 2>/dev/null)" 2>/dev/null
  fi

注意：段落以 Root 权限执行。不要填写来源不明的命令，不要随意 rm -rf，
不要修改 service.d 中的其他服务。错误的 Shell 可能导致 FRPC 定时任务失败。

四、随机路径与日志
------------------
每次生成 FRPC 安装包都会使用新的随机单词作为服务脚本名、数据目录名和二进制名。
手机上的实际路径以“设备详情”显示为准，不要手写旧路径。
日志是否启用以手机上实际日志文件是否存在为准，日志文件没有固定 .log 后缀。

五、安装、卸载和重装
--------------------
安装前由手机端 SH 判断并停止旧的受管理 FRPC 服务，电脑端不会提前卸载，
这样可以避免 ADB 连接被提前断开。
FRPC 卸载只移除 FRPC 服务入口；ADB 服务需要在对应的在线操作中单独卸载。
重装时优先选择在线 ADB 设备，再使用当前归档推送配置。

六、常见问题
------------
1. 手机锁屏后 FRPC 断线：优先检查三星后台省电、Wi-Fi 休眠、移动数据限制、VPN 和代理。
   “network is unreachable”通常表示手机网络路由暂时消失，不是 FRPC 配置语法错误。
2. ADB 连不上：检查 USB 调试授权、TCP 5555、电脑代理是否绕过 adb.exe，以及手机是否在线。
3. 出现端口 already used：通常是两个 FRPC 实例或两个配置使用了同一个远程端口，
   检查 APK 自启动、旧 Shell 服务和当前归档配置。
4. 详情中的路径、时间和定时段落以手机实际读取结果为准；没有 Root 时部分内容不可读。

七、配置文件
------------
电脑端归档：scripts\profiles\<归档名>.json
当前安装配置：scripts\profiles\active.json
手机端 FRPC：/data/adb/service.d/<随机名>.sh 和 /data/adb/<随机目录>/
手机端 ADB 状态：/data/adb/tcp-adb-service-path
手机端 FRPC 状态：/data/adb/service-state

所有修改完成后，建议重新点击“刷新设备”并双击设备查看实际状态。
